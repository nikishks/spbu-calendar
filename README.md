# СПбГУ → Apple Calendar (iPhone)

Готовый проект для автоматической выгрузки расписания СПбГУ в iCalendar (`.ics`),
который можно добавить на iPhone как подписной календарь.

Настройки по умолчанию:
- направление: Менеджмент
- группа: 24.Б02
- выбранный электив: Теория игр

## Как это работает

GitHub Actions запускает Python-скрипт по расписанию → скрипт получает актуальное
расписание СПбГУ → оставляет выбранные предметы → создаёт `docs/schedule.ics` →
GitHub Pages публикует файл → iPhone подписывается на этот календарь.

## ВАЖНО: нужен внутренний ID группы

СПбГУ использует внутренний `studentGroupId`, а не название `24.Б02`.
Поэтому перед первым запуском нужно один раз вписать ID группы в `config.json`.

Самый простой способ:
1. Открой расписание своей группы на timetable.spbu.ru.
2. Найди ссылку/URL страницы расписания группы.
3. В URL будет параметр вроде `studentGroupId=123456`.
4. Скопируй число в `config.json` в поле `student_group_id`.

Если URL не содержит ID, можно прислать мне ссылку на страницу расписания
24.Б02 — я помогу определить его.

## Настройка

1. Создай новый GitHub repository. Для бесплатной подписки календаря через
   GitHub Pages репозиторий проще сделать Public.
2. Загрузи все файлы этого проекта.
3. В `config.json` укажи `student_group_id`.
4. В `config.json` оставь:
   `"subjects": ["Теория игр"]`
   или добавь другие предметы.
5. В GitHub открой:
   Settings → Pages → Build and deployment → Source: GitHub Actions.
6. В Actions вручную запусти workflow `Update SPbU calendar`.
7. После первого успешного запуска файл будет опубликован по адресу:

   https://USERNAME.github.io/REPOSITORY/schedule.ics

   где USERNAME и REPOSITORY — твои данные GitHub.

8. На iPhone:
   Настройки → Календарь → Учетные записи → Добавить учетную запись →
   Другое → Добавить подписной календарь → вставь URL `schedule.ics`.

## Автообновление

Workflow запускается каждые 30 минут и также при каждом push.
Расписание строится на несколько месяцев вперёд.

## Выбор предметов

В `config.json`:

```json
"subjects": [
  "Теория игр",
  "Название другого предмета"
]
```

Фильтр нечувствителен к регистру и допускает частичное совпадение.
Например `"теория игр"` найдёт `"Теория игр"`.

Если поставить:

```json
"subjects": []
```

будут добавлены все занятия группы.

## Источник расписания

Проект использует официальный timetable.spbu.ru и его механизм выгрузки
расписания студенческой группы в Excel.
